## 一、画面怎么读（必须先看懂这套标记，否则会误判）

十六宫盘：**4×4 网格，中间 2×2 合并**成一块放「十六宫天地盘 / 年命亥 / 上南下北」。
十二地支落在周边 12 格，**中心合并格不属地支**。地支方位（固定不动，永远一样）：

```
巳  午  未  申      顶端左侧「三司表头」四格：司天 / 司地 / 司人 / 年命
辰  ██  酉
卯  ██  戌
寅  丑  子  亥
```

格里三层文字（这是本片最容易读错的地方）：
- **天盘支** — 格正中，最大，深翠色，如「酉」
- **天盘干** — 格左下，赭橙色，如「丁」
- **地盘支** — 格右下，灰绿色，如「寅」
- **签** — 格右上角的小方块，自上往下**叠**（一格可同时有「3」和「司地」两枚）

## 四、请重点报告的问题类型

1. **缺/错的天盘支、天盘干**（照第二节两副盘的答案逐宫对）
2. **签的时序**：该在的不在、不该在的提前出现

4. **层掉帧**：`_b` 版本里有没有哪一层突然空了
5. **顺数计步签**：是否出现「0」
6. 其他任何看着不对的地方（错位、重叠、残影、字幕压字）
