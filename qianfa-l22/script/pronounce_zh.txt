# 项目级同音字读音替换（仅影响送给 TTS 的文本；字幕与 timeline 显示原字）
# 格式：原词=同音词，每行一条，# 起注释。
# 硬性要求：原词与同音词必须**等长**（逐字对齐词边界），否则字幕起始点会漂。
# 内置表见 scripts/tts_build.py 的 PRONOUNCE_ZH（天地否→天地痞、雷水解→雷水懈、风天小畜→风天小蓄…）。
# 用法：先跑 python3 ../../scripts/pron_dict.py scan script/narration.txt 拿风险词，再在这里补条目。
#
# 示例（原词是你写在讲稿里的字，等号右边是送 TTS 的同音字；去掉行首 # 即生效）：
# 策轨数=测轨数
# 地天泰=地天太

# ── L22 药方计算姬（2026-10-18 老板指出多音字没考虑到）──
# 1. 「怎么版」是老板原稿的口误梗（办法→版），TTS 读 ban 会像在说"版本"。
#    改成同长的「怎么办」让读音正确，字幕仍显示原稿的「版」。
#    ⚠ 不等长会漂词边界，「怎么版」3 字 → 「怎么办」3 字 ✓
怎么版=怎么办
# 2. 「宫阙」què 是高频错读（quē/què），换同音等长的「宫阕」。
宫阙=宫阕
# 3. 「github」：TTS 常读成"吉特哈布"或逐个字母乱读。换成中文音译等长替换不可行
#    （7 字母 vs 3 汉字），改为在口播里直接说「GitHub」并接受其默认读法；
#    如需精确，改用 SSML 不在本脚本能力内 —— 留待试听后定。
